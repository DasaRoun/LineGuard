# 노트북 서버 전환 가이드 (2차)

> 이 문서는 개발하면서 계속 갱신합니다. Firebase(1차) 코드는 **지우지 않고 보관**하며, 설정 한 줄로 되돌릴 수 있습니다.

## 1. 원칙
- 화면 코드(`src/app`, `src/components`, `src/lib`)는 **수정하지 않습니다.**
- 저장소 관련 코드는 모두 `src/backend/` 아래에만 있습니다.
- 노트북 서버용 구현은 `src/backend/local/` 에 새로 만듭니다.
- 전환 직전 GitHub 에 태그를 남깁니다: `git tag firebase-v1 && git push origin firebase-v1`

## 2. 바꿔야 할 파일 목록

| 파일 | 할 일 |
|---|---|
| `src/backend/local/index.ts` | **신규** — `Backend` 인터페이스(`src/backend/types.ts`)의 모든 함수 구현 |
| `src/backend/index.ts` | `case "local": return localBackend;` 주석 해제 + import 추가 |
| `.env.local` | `NEXT_PUBLIC_BACKEND=local`, `NEXT_PUBLIC_LOCAL_API=https://노트북주소:포트` 추가 |
| `server/` (신규 폴더) | 노트북에서 실행할 서버 (아래 3번) |
| `cors.json`, `firestore.rules`, `storage.rules` | 노트북 서버에서는 사용 안 함 (보관) |

## 3. 노트북 서버 구성 (권장안)

| 기능 | Firebase(1차) | 노트북 서버(2차) |
|---|---|---|
| 실시간 동기화 | Firestore `onSnapshot` | Socket.io (subscribe* → 소켓 이벤트 구독) |
| 데이터 저장 | Firestore | SQLite 파일 1개 (`messages`, `media` + 현재상태 테이블) |
| 파일 저장 | Firebase Storage | 노트북 폴더 `uploads/` + 정적 서빙 |
| 인증 | 익명 로그인 | 접속 시 서버가 임시 토큰 발급 (접속코드 검증) |
| 화면 배포 | GitHub Pages | 같은 서버에서 `out/` 폴더 정적 서빙 |
| HTTPS | 기본 제공 | **필수** (휴대폰 GPS/카메라/마이크) → mkcert 사설 인증서 또는 Cloudflare Tunnel |

## 4. Backend 인터페이스 함수 대응표

| 함수 | 노트북 서버 구현 방법 |
|---|---|
| `ensureAuth` / `currentUid` | 브라우저에 uid(랜덤) 생성·보관, 서버 토큰 요청 |
| `createIncident` / `joinIncident` | `POST /api/incidents`, `POST /api/join` |
| `subscribeIncident/Sites/Dispatches/Messages/Live` | 소켓 `join(incidentId)` 후 `*:snapshot` 이벤트 수신 |
| `updateIncident/Site/Dispatch` | `PATCH` API → 서버가 소켓으로 전체 브로드캐스트. **점(.) 경로 키**(`orders.철수`) 지원 필요 |
| `sendMessage` | `POST /api/messages` |
| `uploadMedia` | `POST /api/upload` (multipart, 진행률은 XHR `upload.onprogress`) |
| `fetchMedia` | 같은 서버이므로 `fetch(url)` → Blob (CORS 문제 없음) |
| `updateLive` / `removeLive` | 소켓 이벤트만 (DB 저장 안 함 — 경로 비저장 원칙 유지) |

## 5. 전환 순서
1. `git tag firebase-v1` 로 현재 버전 보관
2. `server/` 작성 → 노트북에서 실행 확인
3. `src/backend/local/` 구현
4. `.env.local` 에서 `NEXT_PUBLIC_BACKEND=local`
5. `npm.cmd run build` → `out/` 을 서버가 서빙
6. 휴대폰으로 HTTPS 주소 접속 테스트
7. 되돌리기: `NEXT_PUBLIC_BACKEND=firebase` 로 바꾸고 다시 빌드
